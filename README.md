# 🍕 Pizza Sales Analytics Dashboard

An end-to-end data analytics project that analyzes pizza sales using SQL, Excel, and Power BI to uncover business insights and visualize key performance metrics.

---

## 📌 Project Overview

This project focuses on analyzing pizza sales data to answer important business questions such as:

- Which pizzas generate the highest revenue?
- Which pizza sizes are most popular?
- What are the peak order periods?
- Which categories perform best?
- How do sales vary over time?

The project combines SQL for data analysis, Excel for data preparation, and Power BI for interactive dashboard creation.
